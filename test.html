📋 How to Test (Updated UI)

Before you start: Make sure the extension is loaded and reloaded!

  • ✅ Load extension: chrome://extensions/ → Reload AI Browser Risk Intelligence
  • ✅ Open DevTools (F12) to see console logs (DEBUG MODE enabled)
  • ✅ Hover over links to see small risk score card
  • ✅ Click the card to see full details panel
  • ✅ Panel has 2 buttons: Continue Safely (new tab) or Take Risk (current tab)

✅ Safe Links (Risk Score: 0-39%)

Expected: Small card shows "0% LOW RISK" - click card for details

GitHub ~0% Google ~0% StackOverflow ~0% Microsoft ~0% MDN Web Docs ~0%

⚠️ Medium Risk Links (Score: 40-59%)

Expected: Orange card with ~23-40% - click for reasons

Suspicious TLD (.info) ~23% Multiple Subdomains ~12% Multiple Keywords ~24% TLD + Keyword ~31% Deep Path ~8%

🚨 HIGH RISK Links (Score: 60%+)

Expected: Red card with 60%+ score - click card to see panel with 2 options

Direct IP + Keyword ~33% IP + Port + Keywords ~68% TLD + Port + Keywords ~73% Maximum Risk Flags ~95% Ultimate Risk Test ~100%

🔄 Dynamic Link Test (MutationObserver)

Expected behavior: Newly added links should also be detected and show tooltips/interception
